# INCLU

Asistente de IA para inclusión digital, diseñado para personas con discapacidades auditivas y visuales.

## Características

- **Chat de voz y texto** — Escribe o habla con la IA
- **Transcripción en tiempo real** — Convierte voz a texto (Whisper)
- **Lectura de respuestas** — TTS con Orpheus/Web Speech API
- **Descripción de imágenes** — La IA describe imágenes para personas con discapacidad visual
- **Modo offline** — Respuestas predefinidas sin conexión
- **Multiidioma** — Español, Inglés, Portugués
- **Historial persistente** — Guarda conversaciones en localStorage
- **Exportar chat** — Descarga en TXT o PDF
- **Tutorial guiado** — Primera vez con pasos interactivos

## Accesibilidad

- Navegación 100% por teclado
- Alto contraste / Modo oscuro
- Atajos de teclado (Alt+M micrófono, Alt+S leer respuesta)
- Alertas visuales para usuarios con discapacidad auditiva
- Soporte screen readers (NVDA, VoiceOver, JAWS)
- WCAG 2.1 AA

## Inicio rápido

1. Abre `index.html` en tu navegador
2. Ingresa tu API Key de Groq (https://console.groq.com/keys)
3. ¡Listo!

## Tecnologías

- HTML5 semántico + CSS3 + JavaScript vanilla
- API de Groq (Chat, Whisper STT, Orpheus TTS)
- Web Speech API (reconocimiento/síntesis de voz)
