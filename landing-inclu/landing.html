📱 Android

INCLU App

Aplicación Android de inclusión y accesibilidad para personas con discapacidad visual, auditiva, sordociega y motora. Six módulos que combinan cámara, voz, vibración, Bluetooth, NFC y GPS.

  • Ver: Lector de texto con cámara + voz, lupa inteligente, escáner de documentos
  • Escuchar: Transcripción de voz en tiempo real para personas sordas
  • Sentir: Lenguaje háptico de vibraciones (izquierda, derecha, peligro, stop, destino, ayuda)
  • Orientarme: Mapa de lugares accesibles, navegación interior (QR/NFC) y exterior (GPS)
  • Emergencia: Alerta SOS con vibración y ubicación
  • Dispositivos: Conexión BLE con INCLU Band, Cane y Glove

INCLU Writer

Reconocimiento en tiempo real del alfabeto manual del Lenguaje de Señas Nicaragüense (LSN) mediante MediaPipe Hand Landmarks y una red neuronal MLP entrenada con más de 11,600 muestras.

  • 78 features: 21 landmarks × 3 coordenadas + 5 ángulos + 10 distancias
  • MLP profunda: 78 → 512 → 256 → 128 → 64 → 26 con BatchNorm y Dropout
  • 98.31% de precisión en test (88 epochs, class weights, augmentation)
  • Soporte para letras con movimiento (J, S, X, Z) en 3 fases
  • Interfaz completa con autocomplete y predicción de siguiente palabra en español
  • Ejecutable standalone (~39 MB) — no necesita Python instalado

🧠 Machine Learning

Motor de Reconocimiento LSN

El corazón del sistema: un modelo de red neuronal que reconoce las 26 letras del alfabeto manual nicaragüense en tiempo real usando la cámara.

  • MediaPipe HandLandmarker para detección precisa de manos
  • Normalización de coordenadas relativas a la muñeca (invariante a posición)
  • Entrenamiento con class weights para datos balanceados
  • Data augmentation: ruido, escala, rotación
  • Historial de entrenamiento: accuracy 98.31%, loss convergente
  • Captura automática y re-balanceo de muestras incluido

Dispositivos INCLU

Ecosistema de wearables y dispositivos de asistencia conectados vía Bluetooth Low Energy (BLE) que extienden las capacidades de la app Android.

  • INCLU Band: Pulsera háptica con vibraciones direccionales y de alerta
  • INCLU Cane: Bastón inteligente con sensores de obstáculos y feedback háptico
  • INCLU Glove: Guante con sensores de movimiento para traducción de señas
  • Conexión BLE directa sin servidores externos
  • Datos almacenados localmente en el dispositivo
